ProType — Documentation & User Guide

ProType is an interactive font browser and viewport typography tool for Blender 4.2+. It embeds font selection, style switching, and text formatting controls directly into the 3D Viewport header whenever a 3D Text object is active.

1. Installation & Setup

ProType is packaged as a standard Blender 4.2+ extension.

  1. Open Blender 4.2 or newer.
  2. Navigate to Edit > Preferences > Get Extensions.
  3. Click the dropdown menu arrow in the top-right corner of the Preferences window.
  4. Select Install from Disk....
  5. Choose the downloaded ProType package (protype-1.0.0.zip).
  6. Ensure the addon checkbox is enabled under Preferences > Add-ons > ProType.

2. Getting Started

  1. Add a 3D Text object to your scene: press Shift + A > Text.
  2. Ensure the text object is active (selected in the 3D Viewport).
  3. Look at the 3D Viewport Header: the ProType font toolbar appears automatically next to the tool settings.
  4. Click the Font Name button to open the interactive font browser popup.

3. Interactive Font Browser

The font browser provides real-time GPU-rendered previews using actual font binaries.

  • Live Typography Previews: Each row renders sample text in its true typeface so you can evaluate glyph shapes, weights, and proportions before applying.
  • Family Grouping: Typefaces are grouped by family, keeping your list organized and clutter-free.
  • One-Click Apply: Click any font row to immediately assign it to the active 3D Text object (and all selected text objects).
  • Favorites: Click the star icon (★) next to any font to toggle it as a favorite for quick access.
  • Fast Font Cycling Shortcut: Press Ctrl + Mouse Wheel Up or Ctrl + Mouse Wheel Down in the 3D Viewport to step through your font catalog in sequence without opening the popup.

4. Search & Filtering

  • Instant Search: Click inside the search box at the top of the popup and type to filter fonts in real time. Use Ctrl + A to select all text, or double-click to clear/replace queries.
  • Category Filters: Use the Filter popover (funnel icon in the header) to restrict fonts to:
    • Sans-Serif
    • Serif
    • Display
    • Handwriting
    • Monospace
  • Weight Filters (Google Fonts): When browsing online Google Fonts, filter specifically by Thin, Light, Regular, Medium, Semi-Bold, Bold, or Black.
  • Reset Filters & Rescan: The filter popover includes a Reset Filters button and a Rescan Fonts button to refresh newly added fonts on disk.

5. Font Sources & Directory Management

ProType organizes fonts across dedicated source tabs:

  • All: Unified list combining all available fonts.
  • System: Operating system fonts automatically scanned from:
    • Windows: C:\Windows\Fonts and Windows Registry font entries.
    • macOS: /System/Library/Fonts and /Library/Fonts.
    • Linux: /usr/share/fonts and /usr/local/share/fonts.
  • User: Per-user installed fonts (e.g., AppData\Local\Microsoft\Windows\Fonts, ~/Library/Fonts, or ~/.fonts).
  • Custom: Arbitrary folders added by the user in Add-on Preferences (ideal for project font folders or shared studio drives).
  • Google: Over 1,500+ Google Fonts families available to browse, download, and cache locally.

6. Family Styles & Variable Fonts

  • Style Selector: Located directly beside the main font button in the 3D Viewport header. Click it to choose any variant (e.g., Light, Regular, Bold, Italic, Black) belonging to the active font family.
  • Variable Font Support: When using variable .ttf or .otf fonts, ProType identifies all named style instances. Blender natively only applies static font files, so ProType automatically extracts and caches static instances into Blender's user data directory on demand.

7. Quick Typography Popover

Click the typography icon (Small Caps) in the Viewport header to open the quick styling popover:

  • Text Case: Instant one-click transformations:
    • UPPER: Converts text to all uppercase.
    • lower: Converts text to all lowercase.
    • Title: Capitalizes each word.
  • Text Size: Adjust the base font scale.
  • Layout & Alignment:
    • Horizontal and Vertical alignment options.
    • Character Spacing (tracking / kerning).
    • Word Spacing and Line Spacing (leading).
    • Offset X and Offset Y.
  • 3D Geometry:
    • Shear and Offset.
    • Extrude: Add depth to your text.
    • Bevel Depth and Bevel Resolution: Create rounded or chamfered edges on 3D text.

8. Specimen Hover Tooltip

  • Hover over any font row in the browser to trigger an enlarged specimen tooltip.
  • Allows inspection of fine typographic details, serifs, and kerning pairs before applying.
  • Can be enabled or disabled in Preferences > Add-ons > ProType.
  • Customizable specimen text string configurable independently from list row text.

9. Add-on Preferences Guide

Access settings via Edit > Preferences > Add-ons > ProType:

  • Font List Preview:
    • Preview Mode: Choose whether font rows display the typeface's own name (Font Name) or sample text (Custom).
    • Sample Text: The text rendered in preview rows (defaults to Hamburgevons 123).
  • Online Fonts (Google Fonts):
    • Toggle Google Fonts catalog integration.
    • Note: Requires Blender's System > Online Access setting to be allowed.
  • Hover Tooltip:
    • Toggle tooltip visibility on hover.
    • Set custom sample text specific to the specimen preview.
  • Custom Font Folders:
    • Click + to add local project or studio folders.
    • Click - to remove a directory.
    • Fonts in custom folders appear immediately under the Custom source tab.
  • Manage Favorites & Recents:
    • View current counts of starred favorites and recently applied fonts.
    • Use Clear Favorites or Clear Recents buttons to reset saved history.

10. Frequently Asked Questions (FAQ)

Why don't I see the ProType font toolbar in my 3D Viewport?

ProType is contextual: it only appears when an active 3D Text object (FONT type) is selected in the 3D Viewport. If a mesh, curve, or camera is selected, the toolbar remains hidden to save viewport space.

Does ProType require an internet connection?

No. All local font workflows (System fonts, User fonts, and Custom studio folders) are 100% offline with zero network communication. Network access is only used if you choose to browse and download online Google Fonts.

How do I enable Google Fonts?

Two simple steps:

  1. Go to Blender's Preferences > System > Network and allow Online Access.
  2. In Preferences > Add-ons > ProType, ensure Enable Google Fonts is checked.

Once enabled, the Google tab will populate in the font browser. Downloaded fonts are cached locally for offline reuse.

How do Variable Fonts work?

Blender does not natively expose variable font axis sliders. ProType reads the named variation instances defined in the font (such as SemiBold, ExtraBold, Condensed) and generates static TTF/OTF files into Blender's user cache so Blender can apply each variation properly.

Can I apply fonts to multiple text objects at once?

Yes. Select multiple 3D Text objects with one active, then choose a font or use Ctrl + Mouse Wheel. ProType updates all selected 3D Text objects simultaneously.

Which Blender versions are supported?

ProType is built for Blender 4.2 LTS, 4.3+, and newer utilizing the modern Blender Extension system and GPU shader APIs.
